# Back Office Operations & MIS

A portfolio-ready Excel operations workbook for entry-level back-office, operations assistant, inventory and e-commerce operations roles.

## Files
- `index.html` — portfolio website (enable GitHub Pages from `main` / root).
- `Office_Operations_Inventory_Dashboard.xlsx` — Dashboard, Inventory, Stock Ledger, Purchase Orders, Weekly MIS, SOPs and How to Use.
- `Inventory_Import_Template.csv` — sample inventory register.
- `Sample_Stock_Ledger.csv` — synthetic movement records.
- `Three_SOPs.md` — receiving, stock issue/dispatch and daily record verification procedures.
- `Project_Case_Study.md` — problem, logic, metrics and limitations.
- `Portfolio_Entry.md` — resume-ready summary.

## Key features
- 20 fictional SKUs across five categories
- Ledger-based stock calculation
- Stock value and reorder alerts
- Purchase-order outstanding quantities and status
- Dashboard and weekly MIS
- Three documented SOPs

## How to use
1. Open the workbook in Excel or a compatible spreadsheet application.
2. Add receipts as positive movements and issues as negative movements in Stock Ledger.
3. Check current stock and reorder flags in Inventory.
4. Update received quantities and status in Purchase Orders.
5. Reconcile the workbook with authorised records before making real decisions.

## Data and claims
All stock, supplier and order data is fictional. This is an Excel practice model, not a live inventory system or ERP integration.
