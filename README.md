# Office Operations & Inventory Management Dashboard

## What this project demonstrates
A practical spreadsheet workflow for tracking records, prioritising follow-up, and reviewing operational KPIs.

## Files
- `Office_Operations_Inventory_Dashboard.xlsx` — workbook with dashboard, detail register/tracker, and summary chart.
- `documentation/Project_Case_Study.md` — case study and limitations.
- `documentation/Portfolio_Entry.md` — resume-ready description.
- `index.html` and `style.css` — static page for GitHub Pages.

## Data and scope
All records are fictional. This is a portfolio demo; no live third-party integration is claimed.
